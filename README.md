# TransFit

**웹앱: https://transfit-web.vercel.app**

지도 앱의 대중교통 소요시간은 '평균 사람'의 걸음과 환승 시간으로 계산됩니다. TransFit은 **내 실제 통학 기록**으로 소요시간을 다시 계산하고, 도착 마감 시각에서 거꾸로 셈한 **집 나설 시각**을 텔레그램으로 알려줍니다.

THE해커톤 CAMPUS 5조 (김범준·조연준)

## 어떻게 동작하나
1. 웹앱에 출발·도착·도착 목표 시각을 넣으면 카카오 길찾기로 경로를 받아 구간(도보·지하철·버스·환승)으로 저장합니다.
2. 통학할 때 단계마다 버튼을 누릅니다 (집 출발 → 승강장 → 탑승 → 환승 → 도착). 웹이나 텔레그램 버튼으로 누를 수 있고, 지연·우회한 날은 기록 탭에서 제외합니다.
3. 기록이 5회 쌓이면 평균 대신 내 기록의 90% 분위수로 소요시간을 계산합니다. 그 전에는 지도와 같은 기준값(도보 = 거리 ÷ 3.7 km/h)에서 시작합니다.
4. GitHub Actions가 10분마다 출발 시각을 계산해 출발 30분 전, 그리고 출발 직전(실시간 열차·버스 도착 반영)에 텔레그램으로 알립니다.

## 구성
- `web/` — 웹앱 한 장 (Vercel, main push마다 자동 배포)
- `supabase/` — 테이블 `schema.sql`, Edge Function `route`(길찾기 대리 호출), `telegram`(봇 웹훅)
- `watch.py` — 출발 시각 계산·실시간 보정·텔레그램 알림 (`.github/workflows/watch.yml`)
- `plan.md` — 원본 해부, 역설계 실험, 설계

비밀 키와 토큰은 저장소에 없습니다 (`.env.local`, GitHub Secrets, Supabase Secrets에만 보관). `web/config.js`에는 브라우저용 공개 키만 있고 접근은 RLS가 막습니다. 네트워크 캡처(HAR) 원본은 올리지 않았습니다.
